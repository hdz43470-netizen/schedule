# 郑华课表

2026-2027 学年第 1 学期的手机课表查询网页。

## 功能

- 今日课程：显示当天课程和下一节
- 周课表：选择第 1-17 周，查看周一至周五的课程网格
- 学期查询：按课程名、教室或教师搜索
- 实践与课外：课程设计、网络课程和体育课单独列出
- 设置：开学日期自动计算当前周，也可手动指定周次
- PWA：支持添加到手机主屏幕和离线打开

## 使用

用浏览器打开 `index.html`，或在目录下启动静态服务器：

```bash
python -m http.server 8080
```

手机与电脑连接同一网络时，通过电脑局域网地址访问。

## 数据来源

课表数据来自教务系统导出的 2026-2027 学年第 1 学期课程表，存储在 `data.js`。
